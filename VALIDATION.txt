ROOT CAUSE FIXED IN 0.4.1
  The daily file was created every commit for two independent reasons:
  1. DailyNotes used the obsolete five-argument ContentResolver.query().
     Android's DocumentsProvider throws UnsupportedOperationException
     ("Pre-Android-O query format not supported") for that overload, so the
     exact-name lookup always returned no documents.
  2. The file was created with text/plain. The provider then appended .txt to
     the requested name.md, producing name.md.txt and, on later commits,
     name.md(1).txt / name.md(2).txt.
  Fixes: modern query(..., Bundle, CancellationSignal) API; text/markdown;
  persisted document URI; same-day shard merge; full-content rewrite instead of
  relying on provider "wa" append mode.
