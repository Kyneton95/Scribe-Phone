LAUNCH FIX IN 0.4.2
  Cause: MainActivity always called buildUi() in onCreate before checking
  isReady(), then hid the setup body and waited 220 ms before starting the
  service. The system also drew a launcher preview from the full app theme.
  Fix: check isReady() before buildUi(); configured launches install a blank
  paper handoff View, start the service from onResume(), and finish as soon as
  BubbleService.isReady(). A launch-only theme disables the system preview.
  On service failure the setup UI is built lazily and the error is shown.
