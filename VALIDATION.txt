Changes (0.6.7)
  - Planner questions: a transcript such as "what do I need to buy?" is
    answered from Yuvomi (shopping list, tasks, upcoming events). The answer is
    kept in a selectable block in the card; the caption and notification show a
    shortened copy. The transcript still goes into the draft.
  - Reminders: "remind me to call the plumber tomorrow at 9" creates the task
    and a Yuvomi reminder attached to it. A notice confirms the local time.
  - SERVER setting renamed from "Server confirmations" to "Server responses";
    it now covers both confirmations and answers.
  - Parses the optional `answer` field alongside `notice`; servers that send
    only {"text": ...} are unchanged.

Server verification (bark, homeserver, 2026-11-02)
  - Deployed with HOUSEHOLD_TZ=Australia/Melbourne; container date now shows
    AEDT instead of UTC. The prompt's "today" and weekday table follow the
    household day, and remind_at is converted to the naive UTC Yuvomi stores.
  - Questions, end to end (read tool loop, no writes):
      "What do I need to buy?"  -> decision answer
        "You need to buy: sausages, eggs, bread, a Christmas present for tea,
         and milk."
      "What tasks do I have?"   -> decision answer, "You don't have any tasks."
      "What is on my calendar?" -> decision answer, doctor's appointment
        Tuesday 3 November 09:00.
  - Reminder, end to end:
      "Remind me to call the plumber tomorrow at 9."
      -> task id 3, due 2026-11-03 09:00
      -> reminder entity_type=task, entity_id=3,
         remind_at=2026-11-02T22:00:00 (09:00 AEDT next day)
      -> notice "Reminder set: Call the plumber (Tue 3 Nov at 09:00)"
      Test task and reminder deleted; GET /reminders/all and
      /reminders/pending return [] and list_tasks is empty.
  - Dry runs: create_reminder and add_shopping_item both report "dry run" with
    no notice and no writes.
  - Safety: "What do I need to buy?" does not write; a question gate downgrades
    write proposals, and the action-cue gate is unchanged.
  - Non-planner question "What time is it?" returns decision note with a
    summary; it is not treated as a planner answer.
