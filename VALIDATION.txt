LOCAL-MODEL CRASH HARDENING IN 0.5.1
  - LocalAsr now wraps config building, model loading and decoding in
    catch (Throwable), logs under the ScribeLocal tag, releases the stream, and
    converts the failure to an IOException shown in the card.
  - The upload worker catches Throwable instead of Exception and logs under
    ScribeBubble, so a Java/Kotlin Error no longer kills the worker silently.
  - android:extractNativeLibs="true" ensures the arm64 libraries are unpacked
    into the install library directory rather than loaded directly from the
    APK; android:largeHeap="true" gives the Java heap more headroom.
  - If a native SIGSEGV/SIGABRT still occurs, the process will still die; the
    logcat crash buffer is required to identify the failing model/native call.
  - Model files and installed state are unchanged; updating from 0.5.0 keeps
    downloaded models.
